# 小站导航 · 2026-10-10

本项目的入口旨在归纳小站，不把所有站点都解释为城际。本轮新增“市内及周边小站”，与主要独立车站和“城际铁路”并列。现有303个城市中的2,225个独立站点被收进新入口；不合并车站，不改变同一服务直达、不限制站点目的地范围。

上海外层保留上海虹桥、上海、上海南、上海松江、上海西；“城际铁路”保持原5个站点；新小站组收纳11站。金山铁路 · 市域：莘庄、春申、新桥、车墩、叶榭、亭林、金山园区、金山卫。其他小站：金山北、练塘、安亭西。上海南仍留外层，不因兼办市域业务降为小站。

金山铁路小站身份和线路资料由[上海政府站点信息](https://www.shanghai.gov.cn/nw17239/20260313/cc9fe6e3e47a47aca3a55b29cd0fb089.html)及[莘庄开通公告](https://www.shanghai.gov.cn/nw4411/20250105/e7e7af64896845e1af9f6bcd1453e7b2.html)核对。`src/data/local-station-groups.json`保存独立ID、城市、省份及来源；没有把同名地铁站放进铁路网络。

## 导航规则

`src/lib/stationChoiceIndex.ts`统一处理两种组。在原登记的主要站、已明确保留外层的共有枢纽之外，快照收录服务数达到100的繁忙站也保留外层；城市没有上述入口时保留一个可选出发站。剩余非城际成员进入“市内及周边小站”。北京丰台、北京朝阳、清河、福田、深圳坪山等不因旧tier字段为local而被隐藏到小站内。

这是减轻选站列表密度的导航规则，不是官方站级、客流等级，也不代表小站只能到市内。服务数量来自本站接受的快照，后续可通过来源核对精细调整主站白名单。未知线路的小站放在“其他小站”，不编造其所属市域或城际线路。新城市和新站默认应用同一规则，不限于上海。

两种子目录互不重复；外层主要站可与城际组存在同站快捷入口。所有外层和内层入口的并集保持3,105个原独立出发站全部可访问，未开放的pending条目不参与归类。

`?city=...&group=local`和`?station=...&group=local`可刷新恢复；老小站链接自动识别返回组。选择城市或父级清空旧组，切换出发站返回当前组，返回全部站点把键盘焦点交还对应组按钮。原城际链接继续兼容。

## 全城市检查与地图显示

已通过同一个应用索引核对全部342个开放城市、3,105个独立出发站。外层720个主要快捷入口；2,225个local小站加160个仅在城际内的站点，共2,385个独立站从城市外层地图隐藏。65个共有枢纽仍可同时出现在外层及城际内，这是同站快捷入口，不是合并站点。每个城市全部外层及内层入口的并集与原出发站一致，各内层分类互不重叠。

地图跟随当前目录：城市外层只画主要站；进入local/intercity才画对应成员；返回时收起分类成员并清除旧详情。选中一个出发站后的全国直达地图仍按同一服务完整展开，目的地小站不因入口归纳而被删除。选择城际内共有枢纽的地图标记保留当前目录。城市地图自动缩放最多到11，以减轻集中主站的标签重叠；全国网络缩放规则不变。

逐城数目、ID及检查脚本见 [全城市审计](CITY-CHOICE-AUDIT.md) 与 `scripts/auditStationChoices.mjs`。303城有local分类，其余城市依自身成员显示城际入口或主要站，不创建空分类。暂无没有外层站的城市；没有繁忙主站的城市仍保留一个直接入口，例如黔西南保留威舍，其余六站在小站组。
