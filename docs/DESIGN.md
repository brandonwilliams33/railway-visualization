# 沿线视觉方案 · 2026-10-10

用户要求更接近苹果的审美，地图仍是第一屏的主角。采用轻盈的系统工具界面：清楚的层级、系统字体和冷白表面，强调色用于选择与路径。

## 设计标记

|用途|颜色|
|---|---|
|页面|`#f5f5f7`|
|表面|`#ffffff`|
|正文|`#1d1d1f`|
|次要文字|`#6e6e73`|
|选择与操作|`#0071e3`|
|分隔|`#d2d2d7`|

字体采用 Apple 系统字体优先、苹方中文，其他平台回退到本机无衬线字体。不依赖远程字体。标题 28px / 600，正文 14px，地图标签 12px，辅助文字 11–12px，统计数字使用等宽数字。

## 布局

全页面左对齐。地图采用最大的圆角容器；目录用文字和分隔线组织，避免所有内容都套成相同卡片。

```text
沿线                                 关于 / 切换
标题与说明
[区域] [省份] [城市]                 选择提示
[独立车站] [独立车站] [城际铁路]
┌───────────────────────────────────────────┐
│ 地图标题                    底图   +      │
│                                   −      │
│         地理地图与共用线路           全图   │
│ 图例                          选中详情    │
└───────────────────────────────────────────┘
直达统计 → 按省份展开的站点目录
```

手机上出发地三步仍为一行；长车站列表独立滚动。地图控件保持 44px 操作面积；详情移至地图下方，不挡住地图。

## 对照需求的调整

“苹果”用于交互表面的简洁层次，不做宣传页或大标题首屏。保留地图与原有两级城际入口，蓝色只用于交互和选中路径，普通走廊以灰蓝色呈现。去掉原来的奶油绿、衬线数字和多层覆盖样式，统一样式层级。不同车站仍有独立标记、ID 和客运服务。

只有地图浮层采用少量半透明与模糊；其余信息采用实色、低阴影，保证阅读清楚。键盘焦点可见，减少动态效果的系统偏好受到尊重。完成后以桌面与手机截图检查地图占比、溢出、选中路径和长城际列表。

## 实际页面复核

1280×800首页地图从237.6px开始，首屏没有车站卡片或目的地目录。苏州城际分两条线路显示，桌面两列导航把地图起点从初稿472px压到418.6px；154px上限容纳两组按钮，超长目录保留滚动。390×844手机网络地图从309.8px开始，详情在地图下方；320px窄屏首页也无横向溢出。广州长目录保持140px高度，并验证了键盘滚动和后段站点选择。

复核后去掉旧的绿/陶土色与衬线字体，保持一套冷白/蓝色系统。地图形状、车站身份和服务关系未随主题改变。进一步将小屏区段入口与图例上下错开，避免320px宽度时挤在同一行。截图见screenshots/preview-apple-*.jpg。
