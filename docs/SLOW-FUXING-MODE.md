# 普速复兴号模式

新增“列车类型 → 普速复兴号”，用于探索走普速线路、提供二等座的CR200J类动车网络。地图、直达目录、搜索、省份筛选、统计和详情使用同一份筛选服务，相关车次显示标签。分享链接使用`type=slow-fuxing`，刷新恢复。

中国中车的[CR200J3-C资料](https://www.crrcgc.cc/dl/2025-06/26/article_2025062608284834261.html)介绍二等座配置及C921/924、C923/922实例；[CR200J-D资料](https://www.crrcgc.cc/zj/2024-09/04/article_2024090414263867838.html)介绍160公里级车型及C776实例。这些资料支持车型与实例，不证明下述整个号段的每一趟车均使用该车型。

## 归类依据

现有时刻快照没有逐车次实时车型字段，本模式按项目维护的号段推断。规则在`src/data/slow-fuxing-rules.json`，应用入口在`src/lib/trainTypes.ts`：

| 快照车次 | 快照源日期下限 |
| --- | --- |
| D1—D300 | 2024-01-10 |
| C11—C998 | 2021-10-11 |

仅处理已接受客运服务，要求号首与category一致、单一合法车次号及有效源日期。这是项目号段推断，不是官方逐车次车型核验清单；页面明确显示“按车次号段归类”。

不把所有D/C车次归入；D315、D351、C2201等不会因为字母相同进入。历史D7xx号段不套用到现行快照，以免号段复用误归类。S/Z等缺少车型依据，不自动加入。未来取得逐车次车型资料时，应维护带日期和来源的明确归类，再更新审计与回归。

未接入实时票价、余票或席别查询。“便宜”是用户提出模式的动机，筛选本身不比较价格；实际车型、席别、票价和是否开行以12306为准。

原“高铁 / 动车”仍包括G/D/C，原“普速”成员不变。新模式是单独选择的子集，旧分享链接含义保持。各站独立身份、小站归纳和共用走廊画法保持；同一服务完整停站决定直达，不引入换乘关系。

## 当前快照审计

2026-10-10审计：1,130个服务记录符合规则，覆盖523个独立出发站、191城。这是已接受快照的推断覆盖，不能解读为全国现行车型全量。

徐州站筛出57个直达站点、11个省级地区、35个相关服务记录，含C979/C980、D61、D121/D122等。C979来源表有徐州停站与一等座/二等座，车型仍按规则推断。方向、径路变化或不同来源可能分别成记录，35个服务记录不等于35趟当日独立列车。

运行`npm run data:audit-fuxing`直接加载应用筛选函数，生成`docs/slow-fuxing-audit.json`。记录含`basis=number-band-inference`、`completeFleetVerification=false`与各站车次。更新服务快照或规则后应重跑。

新增回归覆盖日期和车次边界、分享状态、全部3,105个出发站的筛选完整性与空网络、徐州省份/搜索联动。完整验证见`VERIFICATION.md`；实际页面截图为`docs/screenshots/preview-slow-fuxing-*.jpg`。
